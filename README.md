# Coin_flip_app
🪙 Coin Flip App

A modern and interactive Coin Flip web application built using HTML, CSS, and JavaScript.
The app simulates a real coin toss with smooth 3D flip animations and keeps track of Heads and Tails results.

🚀 Features
Realistic 3D Coin Flip Animation

Random Heads or Tails Result

Heads & Tails Score Counter

Reset Button

Responsive Modern UI

Smooth Transitions & Effects

Interactive Buttons

🛠️ Technologies Used
HTML5

CSS3

JavaScript


📂 Project Structure
coin_flip_app/

│── index.html

│── style.css

│── script.js

💡 How It Works

User clicks the Flip Coin button

JavaScript generates a random result

Coin rotates with animation

Result is displayed on screen

Heads and Tails counts are updated automatically

▶️ How to Run

Download or clone the repository

Open project folder

Run index.html in browser
